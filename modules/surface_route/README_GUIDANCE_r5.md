# R5：平滑路径的分岔引导与同标量场渲染

本模块已完成 Windows、ARM 和实际 PL 对照，尚未替换默认 HDMI 导航。测试后恢复原 R17 界面和 C6 渲染。原概率场／各向同性 SDF 的完整界面接入仍需继续完成。

## 修复的实际缺口

R4 在自带 CT 的 1 mm 最小弯曲半径约束下，产生 877 个点、长 166.762 mm 的平滑路径。旧引导使用“距离原中心线小于约 0.23 mm”的匹配方式；平滑路径有约 2.17 mm 的位移，导致 3 个分岔提示全部被漏掉。

R5 在物理弧长重采样、Gaussian 提议及最终重采样过程中保留原路径参数，将原始森林中实际选择的分岔沿此对应关系映射到新路径。没有重新猜测最近分支，也没有用新旧总长度比例代替对应关系。

路径点、原中心线节点编号、全部管径／弯曲审核数组和相机与 R4 逐项一致；新增的是引导对应数据。原 R4 源码、结果、原气道掩膜及 PL 网格均保留。

3 个目标分支仍为 80、51、52。只有根节点的不可前进路径不产生向前入口提示。此 CT 的路径仍属于有限可达，末端距候选区域约 81.36 mm，没有宣称已到达候选区域。

## 表面与标记如何保持一致

分支拓扑和子代归属来自原中心线森林。入口截面和可见性根据实际用于 C9 渲染的 Q5/Q6 标量场计算；原分支覆盖经物理坐标映射后，裁剪到同一标量场的正值区域。

因此，绿色目标标签、黄色轮廓、深度和法线使用同一份标量数据。标量距离仅用于提示尺寸，器械余量仍由已有实际三角网格和连续段审核提供。缺失有效标签的分岔会显式标为不可用，不会画出错误入口。

这一版实际输入是已验收的原生体素表面规则，不能当作原概率/SDF规则已完成接入的证据。

## 验证结果

- Windows 和 ARM 均通过 7 组几何、分支归属及拒绝错误输入的测试。
- Q5/Q6、弯曲约束 0／0.05／1／10 mm 共 8 组新鲜重算，与各平台 R4 的全部路径审核数组和相机一致。
- 平滑的 1 mm 路径由旧引导的 0 个提示恢复为 3 个；Q5/Q6 均如此。
- 两平台目标标签逐体素一致，6 份完整 C9 场景／镜头请求／参考像素输入包逐字节一致。
- 板卡实际运行 6 组 640×363、最多 1023 步的画面；全部 232,320 个深度、法线、目标与轮廓像素与 PS 一致，四个完整 4096 字节 DMA 保护区通过。
